# EVE OS — Documentação Oficial

Esta pasta é a fonte da verdade do produto EVE OS (Event Intelligence
Operating System), a plataforma de inteligência criativa para empresas de
eventos que nasce do trabalho da Tia Bia Festas / Método Bia Azevedo.

Todo código do monorepo deve ser construído em conformidade com estes
documentos. Quando houver dúvida entre "o que o código faz" e "o que estes
documentos dizem", os documentos vencem — o código deve ser corrigido, não
o contrário.

## Origem

O conteúdo foi transcrito de uma sessão de planejamento de produto (ver
histórico da conversa desta branch) que partiu da análise de um orçamento
real de casamento (Karen & Daniel, Villa Massari) até a definição do
blueprint do EVE OS. Está registrado aqui verbatim/organizado por capítulo
para não se perder, e deve ser expandido conforme o produto evolui —
conforme o Capítulo 9 da Constituição, esta documentação é um organismo
vivo.
